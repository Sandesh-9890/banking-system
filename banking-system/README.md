# Banking System (Spring Boot + JWT)

##  Features
- Account creation
- Deposit / Withdraw
- Fund Transfer
- Transaction History
- JWT Authentication
- Input Validation
- Global Error Handling

## 🛠 Tech Stack
- Java 21
- Spring Boot
- MySQL
- JPA (Hibernate)
- JWT (Authentication)

## 🔐 Authentication
- Login API returns JWT token
- All account APIs are secured

## Run Backend

```bash
mvn clean install
mvn spring-boot:run
